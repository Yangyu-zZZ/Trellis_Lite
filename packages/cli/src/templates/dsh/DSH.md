# Trellis Lite on DeepSeek Harness

Initialize with `trellis init --dsh -u your-name`.

Discuss requirements with `trellis-brainstorm` and keep the agreed goal, scope, constraints, and acceptance criteria in the task's `prd.md`. Continue implementation directly in the current main session, reading relevant specs and choosing appropriate validation tools.

Use the platform's Trellis start/continue/finish-work entries to load context, resume a task, and record outcomes. Specs, PRDs, task metadata, and developer journals live under `.trellis/` and can be reused by any other configured platform.
